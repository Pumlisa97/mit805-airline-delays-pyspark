Dataset
Source
This project uses the U.S. Bureau of Transportation Statistics (BTS) Reporting Carrier On-Time Performance dataset.

TranStats Portal:

https://www.transtats.bts.gov/

Dataset Sizes
Dataset Stage	Size
Raw Dataset (2015–2024)	26.495 GiB
Download Archive	2.971 GiB
Working Dataset (2020–2024)	14.130 GB
Processing Dataset	60 monthly files
Important Note
The raw BTS data is not included in this repository due to its size and redistribution considerations.

Users wishing to reproduce the analysis should download the data directly from the BTS TranStats website.

Processing Period
January 2020 to December 2024

Analysis Focus
The project investigates the relationship between scheduled departure hour and the likelihood of a completed flight arriving at least 15 minutes late using PySpark and MapReduce-style distributed processing.
